# 你说中文了

一个「语言边境审批」小游戏的单文件实现：所有样式、逻辑与像素立绘（内联 SVG）都在 `index.html` 里，没有构建步骤，也不需要联网。

打开方式：下载后用浏览器直接打开 `index.html`（双击即可）。

## 玩法

右侧不断飘来带对话框的文本，玩家判断其中是否含有汉字：含汉字就拒绝，不含就放行。被拒绝的文本在触及分界线时消失，被放行的文本继续向左飘走。

| 操作 | 放行 | 拒绝 |
| --- | --- | --- |
| 鼠标 | 左键 | 右键 |
| 键盘 | `A` | `D` |

其他按键：`空格` 开始 / 暂停，`R` 重置回未开始状态并清空计分板。左下角另有重置与暂停按钮，以及关卡选择。

左上角计分板依次为：成功阻止的中文、成功放行的非中文、误操作、漏处理（越过判定区时玩家没有点过的条目计入这一项，不算放行）、以及准确率。

## 音乐关卡

除默认的「自由审批」外，另有三首按音乐节拍出怪的关卡：

1. 《您的账号已被封禁》 · 原作者 BiliBili@风霜秋雨
2. 《world.execute(me);》 · 原作 BiliBili@ProjectMili · 改编 BiliBili@真寻Mahiro
3. 《人是猫》 · 原作 BiliBili@张卡斯

每首曲子有简单（每小节一击）、普通（每两拍一击）、困难（每拍一击）三档难度。同一难度下出怪节奏恒定，节拍点对齐文本走到判定区中心的那一刻。

**音轨不在仓库里分发。** 想玩音乐关，请把三首曲子的 mp3 以下述同名文件放在 `index.html` 同目录：

```
level1.mp3
level2.mp3
level3.mp3
```

页面里也提供了「音轨」选择器，可以临时从任意位置载入音频；音频不可用时游戏会自动退回按秒计时的静音节拍模式，不影响操作与计分。

节拍图（起拍时间、拍长、拍数）是在本地对音轨做起始能量检测与梳状搜索得出的，已固化在 `index.html` 里，因此换用不同码率的同一份音频不会改变谱面。

## 关于语料

内置 402 条短语、74 个语言分组，覆盖中、英、日、韩、法、德、西、葡、意、俄、阿、希伯来、泰、越、印地、土耳其、印尼等语言与方言写法，以及大量「人类对 AI 的开场白」。汉字判定使用 Unicode 汉字区段（含扩展 A 与兼容表意文字），假名、谚文与罗马音均不计为中文。
